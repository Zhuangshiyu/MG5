## Devlog
1. NavMesh is better for NPCs that need automatic pathfinding, like villagers walking around a town. Physics is better for platformers like Super Mario Bros, where jumping and gravity are important.
2. The loop checks every bird in _birds. Vector3.Distance calculates the distance between each bird and the player. Only birds within _interactDistance will run away.
